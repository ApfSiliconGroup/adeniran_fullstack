Adeniran Street Clinic Booking API

Team 3

A beginner-friendly FastAPI backend for the Adeniran Street Clinic.

The clinic previously used a paper diary, which caused double-booking and made it difficult to know who accessed a patient record. This API provides patient booking, doctor appointment management and receptionist diary management.

 Technologies

- FastAPI
- Python
- SQLModel
- SQLite
- JWT token authentication
- Password hashing with bcrypt
- APIRouter
- Dependencies
- Middleware
- CORS
- BackgroundTasks
- Pydantic models
- Swagger `/docs`
